How an update flows

  1. Save or drop the workbook into the Dashboard Data library (here, or from Excel's Save As to SharePoint). Versioning keeps every prior copy.
  2. The page reads the file directly through Microsoft Graph on every load: the five sheets above, cached values, no formulas re-run.
  3. Everyone sees the new figures on their next visit. The stamp at the top shows the version, time and uploader so a stale file is obvious.

The page keys off sheet names and header labels, never cell addresses. If a sheet or column is renamed, the panel above shows which one is missing instead of showing wrong numbers.
